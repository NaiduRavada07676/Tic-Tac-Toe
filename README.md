# 🎮 Tic Tac Toe Game

A simple and interactive **Tic Tac Toe game** built using **HTML, CSS, and JavaScript**.

The game allows two players to play Tic Tac Toe on the same device. The application automatically detects winners, draws, and keeps track of the game status.

## 🎮 Features

- ❌ Player X and ⭕ Player O gameplay
- 🏆 Automatic winner detection
- 🤝 Draw detection
- 🔄 Restart game option
- 📊 Game status display
- 📱 Responsive design
- ✨ Simple and interactive user interface
- ⚡ Fast and lightweight

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
